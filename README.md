# SPECTRAL | Professional Chromatic Extraction

SPECTRAL is a premium, high-performance web tool designed for professional color extraction from any image. Built with a focus on aesthetics and utility, it transforms visions into functional color palettes with laboratory precision.

---

## 🚀 Features

- **Extreme Performance**: Optimized color sampling using pure JavaScript (No external heavy libraries).
- **Premium UI**: Modern dark-mode aesthetic featuring glassmorphism effects and smooth micro-animations.
- **Smart Extraction**: Identifies the 5 most dominant and visually distinct colors.
- **Developer Workflow**:
  - **Copy Individual Hex**: Click any card to copy its code.
  - **Copy All**: Export all hex codes in one click.
  - **CSS Export**: Instantly generate `:root` CSS variables for your project.
  - **Detailed Info**: View both HEX and RGB values for every color.
- **Interactive Workspace**: Seamless drag-and-drop experience.

## 🛠️ Tech Stack

- **Core**: JavaScript (ES6+ Modules)
- **Styling**: Tailwind CSS & Vanilla CSS
- **Build Tool**: Vite

## 📦 Installation & Usage

1. **Clone the repository**:
   ```bash
   git clone https://github.com/gabri98gim/spectral.git
   cd spectral
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run in development mode**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
